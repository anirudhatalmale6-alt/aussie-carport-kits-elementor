Chloe Hart website: install steps

Free Elementor only. Takes about 15 minutes. Do the steps in this order.

In the zip:
1-chloe-hart-homepage.json (the homepage)
2-chloe-hart-header.json (header with menu, shows on every page)
3-chloe-hart-footer.json (footer, shows on every page)
4-chloe-hart-additional-css.txt (the CSS for the stacking cards and still backgrounds)

Step 1: Theme and plugins

  1. Appearance > Themes > Add New: search Hello Elementor, Install, Activate.
  2. Plugins > Add New: install and activate Elementor (free).
  3. Plugins > Add New: search Ultimate Addons for Elementor (by Brainstorm Force, formerly "Elementor Header & Footer Builder"), install and activate.

Step 2: Import the 3 templates

  1. Templates > Saved Templates (in the Elementor menu), click Import Templates.
  2. Import 1-chloe-hart-homepage.json, then 2-chloe-hart-header.json, then 3-chloe-hart-footer.json. The book covers download into her Media Library automatically.

Step 3: Create the homepage

  1. Pages > Add New, title it Home, click Edit with Elementor.
  2. Click the grey folder icon (Add Template), open the My Templates tab, find Chloe Hart — Homepage and click Insert. If it asks to apply the template's page settings, choose Yes.
  3. Bottom-left gear icon (Page Settings): set Page Layout to Elementor Full Width. Click Publish.
  4. Settings > Reading: "Your homepage displays" = A static page, Homepage = Home. Save.

Step 4: The menu

  1. Appearance > Menus: create a menu called Main menu.
  2. Under Custom Links add three links:
    /#booksThe books
    /#aboutMeet Chloe
    /#listNewsletter
    Save Menu. (Later, add the book pages here too.)

Step 5: Header and footer

  1. In the left admin menu go to UAE > Header & Footer and click Add New.
  2. Title Header, Type of Template = Header, Display On = Entire Website. Click Publish, then Edit with Elementor.
  3. Folder icon > My Templates > Chloe Hart — Header > Insert. Click the menu widget and make sure Main menu is selected. Update.
  4. Repeat for the footer: Add New, title Footer, Type = Footer, Display On = Entire Website, insert Chloe Hart — Footer, Update.

Step 6: The CSS (makes the cards stack and the backgrounds stay still)

  1. Appearance > Customize > Additional CSS.
  2. Open 4-chloe-hart-additional-css.txt, copy everything, paste it into the box and click Publish.

Step 7: Her own content

NewsletterMailerLite: Forms > Embedded forms > Create, add First name + Email, save and copy the HTML code. In Elementor, click the form in the pink "Get on the list" card (an HTML widget) and replace its content with that code. The CSS is set up to restyle MailerLite's standard form to match the card. Easiest: send me the code and I'll put it in and check it.
Author photoClick the arch image in "Hey, I'm Chloe" and choose her photo (portrait works best).
Buy linksThe Buy buttons and covers link to Amazon Australia. Change them in each button's Link field if she uses other links.
InstagramInstall Smash Balloon Instagram Feed (free) and connect her account. Then delete the 6 placeholder tiles and add a Shortcode widget with [instagram-feed].
Tip: if anything looks unstyled after importing, go to Elementor > Tools > Regenerate CSS & Data, then clear any caching plugin.
